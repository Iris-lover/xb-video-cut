# XB Video Cut

面向 ChatCut Desktop 的 AI 视频剪辑 Skill。以说话内容为主线，先完成 A-roll 语音剪辑，再按最终时间线处理字幕、背景音乐、转场与音效、B-roll 和 MG 动画。

适合单人口播、访谈、视频播客、课程、教程和讲解视频。需要已有源素材；本仓库提供执行规范与判断手册，不包含 ChatCut 应用、剪辑引擎或媒体素材。

## 安装与使用

将整个仓库目录放入你的 Agent 支持的 Skills 目录，目录名称保持为 `xb-video-cut`，并保留 `references/`。例如 Claude Code：

```bash
git clone https://github.com/Iris-lover/xb-video-cut.git ~/.claude/skills/xb-video-cut
```

若目标目录已存在，先备份或比较内容，不要覆盖自己的修改。私有仓库需要先登录有访问权限的 GitHub 账号。其他 Agent 按各自的 Skill 安装方式配置；实际剪辑需要能访问 ChatCut Desktop 的工具环境。

在 ChatCut 打开目标项目，然后向 Agent 提出需求，例如：

> 使用 xb-video-cut 清理当前口播的口癖、失败重录和长停顿，保持自然节奏；先给我看语义剪辑方案。

> 继续当前视频：为已确认的口播添加字幕，沿用项目样式。

> 先规划 B-roll 素材表，区分需要我上传的真实素材与建议生成的画面，确认后再制作。

成功加载后，Agent 应先核对目标项目、素材和需求，再执行你启用的阶段。

## 剪辑流程

**第一排：口播与基础包装（1 → 6）**

```mermaid
flowchart LR
    A["1. 项目与素材确认"] --> B["2. A-roll 语音剪辑"]
    B --> C["3. 确认最终口播"]
    C --> D["4. 字幕"]
    D --> E["5. 背景音乐"]
    E --> F["6. 转场与音效"]
```

**第二排：承接步骤 6，完成视觉与交付（7 → 12）**

```mermaid
flowchart LR
    G["7. B-roll"] --> H["8. MG 动画"]
    H --> I["9. 最终检查与素材归档"]
    I --> J["10. 确认导出"]
    J --> K["11. 交付与项目备份"]
    K --> L["12. 按需衍生竖屏版"]
```

以上是推荐顺序，字幕以后的增强项按需启用，可以跳过。A-roll 必须先于依赖最终口播时间线的处理；只要求单项时，不自动扩展为全流程。

| 阶段 | 主要处理 | 确认与验证 |
|---|---|---|
| 项目准备 | 检查项目、素材、画布与既有风格 | 只补问无法从项目确定的关键信息 |
| A-roll 语音剪辑 | 清口癖、删失败重录、压缩停顿、必要时重组 | 保留完整语义和操作步骤；重新读稿并检查接缝 |
| 字幕 | 按意群分卡，检查跨卡词组和句尾标点 | 完整读取并回读保存结果，提供全文供确认 |
| 背景音乐 | 少量试听候选，按真实情绪边界铺设 | 选定方向后落轨，检查 ducking 与内容结束点 |
| 转场与音效 | 转场表与情绪音效表独立维护 | 转场点先确认，每个转场特效配套转场音效 |
| B-roll | 先核对实际画面，再按口播匹配 | 批量规划先确认总表与来源；视频完整保留、加速优先 |
| MG 动画 | 先判断内容与形式，再出 HTML 静态稿 | 方向未定先给三案，确认后制作动画并检查进出场 |
| 导出与归档 | 检查画面、声音、字幕，复制归档并重新关联 | 导出前确认，交付后提醒完整项目和依赖备份 |
| 横转竖 | 复制时间线、contain 适配、字幕字号换算 | 不覆盖横屏；MG 按需烘焙，真实导出抽帧验收 |

## 使用约束

- 已有画布、字幕与品牌风格优先；新项目无要求时才使用 1920×1080 / 60 fps 默认值。
- 启用的主要阶段完成后通常等待确认；“继续”“下一步”“确认”可用于推进。
- B-roll、转场与音效表统一维护在该视频的同一份 Obsidian 脚本文档中；首次使用需要提供实际文档位置。
- 本仓库已移除作者个人脚本文档映射，并将本机字体路径和素材归档位置改成占位说明；使用时配置自己的目录。
- 生成素材与付费操作需遵循用户授权。即梦／Dreamina／Jimeng 的任何生成操作均需当次明确同意，不能把清单确认当作生成授权。
- 像素章节标题依赖 `GuanZhi 8px` 字体，本仓库不分发字体文件；缺失时应报告。
- 章节进度条交给独立 Skill `xb-video-timeline`；该 Skill 以及 `xb-video-style` 不随本仓库分发，相关功能需另行配置。
- ChatCut 的工具、权限与行为可能随版本变化。文中的历史问题和处理方法来自实操记录，执行时仍需检查当前环境，不应将工具返回成功视为成片验收。
