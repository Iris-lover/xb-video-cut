# 素材表驱动的 B-roll 工作流

适用于用户提供 B-roll 素材清单、checklist、分镜表或包含“口播锚点、所需画面、建议时长、对应素材”的规划文件，并希望把素材库内容放到对应口播位置的任务。

若用户还没有确认画面素材表，先按主 SKILL.md 第 8 节制作一张统一的待确认总表；在用户确认画面需求和建议来源之后，才拆为“用户上传真实素材”和“Agent 生成素材”两份执行清单。本文件以下的素材匹配与落轨步骤只用于已确认的清单，不能把未确认表当作生成或放置授权。

## 1. 先建立事实，不按文件名猜

1. 读取目标时间线、画布比例、帧率、现有轨道、字幕和口播文字稿。
2. 完整读取素材表，提取每一行的口播锚点、画面需求、建议时长、展示重点和已知限制。
3. 浏览当前素材库，并检查候选图片的实际像素、候选视频的全片概览与关键源画面。文件名只能用于初筛，不能证明素材内容。
4. 按实际画面建立匹配：口播锚点、目标时间范围、候选素材、完整源时长、处理方式、画面适配方式、是否缺失或存在歧义。
5. 素材缺失、内容与清单明显不符、需要付费生成，或不同匹配方案会显著改变成片时，先向用户确认；能够从口播和实际画面唯一判断的匹配直接执行。

按 SKILL.md 第 2.1 节，将素材匹配结果及后续变更更新到该视频的 Obsidian 脚本文档中的素材表；不得另建并行维护的清单。用户已授权的清单维护无需再次询问；素材表本身不自动授权付费生成、时间线修改或导出。

## 2. 以口播语义确定目标区间

- 口播锚点优先使用当前文字稿定位，不能只依赖素材表里可能已经过时的四舍五入秒数。
- B-roll 的开始与结束应覆盖完整语义单元：对象被提及时切入，说明完成或话题转移时切回。
- UI、文档、操作录屏和结果对比通常使用全屏切换，以保证文字与操作可读。
- 默认不在成片开头或结尾 3 秒内切走，除非素材表或内容本身明确需要。
- 相邻锚点由同一长素材覆盖时，可以把它们规划为连续段落，减少不必要的来回切换。

## 3. 视频素材：完整保留与加速优先

处理每一段视频时使用以下优先级，不能跳级：

1. **完整素材加速适配**：先计算完整源时长与目标展示时长的比例，在产品允许范围内设置恒定倍速，让素材从源开头播放到源结尾。不能把“设置较短 duration”误当成加速；必须复查实际源范围覆盖了完整素材。
2. **在相关口播内延长覆盖**：完整素材按允许倍速仍稍长时，检查前后是否仍在讲同一对象、步骤或结果。语义相关且不会挤掉更重要的 B-roll 时，可以适度延长覆盖范围。
3. **协调相邻 B-roll**：两个连续素材共享同一段口播区间时，分别计算倍速和时长，让两段完整源素材首尾相接地放入整段相关口播，而不是固定保留旧切点后剪掉其中一段。
4. **最后才剪辑**：达到允许速度上限、扩展到完整相关口播后仍放不下，才允许剪辑。优先删除等待、加载、静止、重复和无关操作；保留关键点击、可读文字、状态变化与最终结果停留。

补充规则：

- 不为了“看起来更自然”擅自剪掉用户要求完整展示的步骤；倍速过高但仍在允许范围内时，先按用户的加速优先偏好执行。
- 视频 B-roll 默认关闭或静音源音频，保留主口播与背景音乐。
- 加速后检查首帧、若干中间帧、尾帧以及相邻素材的衔接帧，确认画面确实随源内容推进，而不是静止、重复或提前结束。
- 如果用户明确指定某一段“加速而不是剪切”，必须验证该段的源范围从开头覆盖到结尾；工具返回成功但源范围只覆盖局部，不能算完成。

## 4. 图片与画面适配

- 先比较图片比例与时间线画布比例，并识别文字、UI、Logo、卡片边缘等受保护内容。
- 不是 16:9 或直接铺满会裁掉受保护内容时，前景使用 `contain` 完整显示，下方增加全屏黑色蒙层/底板；不要让底层口播画面从两侧露出。
- 连续图片可以共用一段黑色底板，前景图片按口播内容切换。
- 接近 16:9 且边缘没有受保护内容时，可以使用安全的 `cover`；不能把 `cover` 当作批量默认值。
- 字幕通常继续显示在 B-roll 上方；预览时确认字幕没有遮住素材的关键文字或操作区域。若冲突会影响理解，调整素材构图、切换时机或先向用户确认取舍。

## 5. 落轨与检查

1. 使用独立的 B-roll 视频轨；需要黑底图片时，用较低的轨道放底板，较高的轨道放前景图片。
2. 同轨素材不得重叠。连续素材的结束帧和下一段开始帧应严密衔接；不要留下意外空隙或黑帧。
3. 修改前读取将要变更的具体项目，修改后只回读受影响的项目或轨道。
4. 对每个 B-roll 段至少检查一个代表帧；涉及切点、加速、相邻素材衔接时，还要检查开始前一帧、开始帧、结束前一帧和结束帧。
5. 视频加速必须核对：时间线时长、倍速、源起点、源终点、静音状态；图片必须核对：完整显示、黑底、裁切和字幕遮挡。
6. 最终确认没有意外空档、重叠、黑帧、重复内容、错误素材、字幕遮挡或 B-roll 原声混入口播。

向用户汇报时使用内容语言说明：哪些口播段落已覆盖、长素材如何加速或为何必须剪辑、图片如何适配，以及哪些结果已经通过画面检查。不要展示内部项目 ID、帧号或工具参数。
